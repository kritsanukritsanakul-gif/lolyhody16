Fed Funds Rate
อัตราดอกเบี้ยนโยบาย — Federal Reserve
อัตราดอกเบี้ยที่ธนาคารกลางสหรัฐ (Fed) กำหนดให้ธนาคารพาณิชย์คิดดอกเบี้ยกันเองในตลาดเงินข้ามคืน ถือเป็น เครื่องมือหลักในการควบคุมเศรษฐกิจ เมื่อ Fed ขึ้นดอกเบี้ย ต้นทุนการกู้ยืมทั่วระบบสูงขึ้น ชะลอการใช้จ่ายและเงินเฟ้อ เมื่อลดดอกเบี้ย กระตุ้นเศรษฐกิจและการลงทุน
🔴ระวัง: ดอกเบี้ยสูงนาน → เสี่ยงเศรษฐกิจถดถอย สินเชื่อแพง ตลาดหุ้นกดดัน
🟢ดี: ดอกเบี้ยลด → ต้นทุนกู้ยืมลด กระตุ้นการลงทุนและการบริโภค
💡ติดตาม: การประชุม FOMC 8 ครั้ง/ปี — ดู dot plot และ forward guidance
เผยแพร่โดย Federal Reserve
ระดับ neutral ~2.5–3.0%
ปัจจุบัน 3.75%
🛒
Consumer Price Index (CPI)
ดัชนีราคาผู้บริโภค — YoY %
วัดการเปลี่ยนแปลงราคาสินค้าและบริการที่ครัวเรือนซื้อในชีวิตประจำวัน ครอบคลุมหมวดหมู่หลักกว่า 200 รายการ ได้แก่ อาหาร พลังงาน ที่อยู่อาศัย การขนส่ง สุขภาพ เป็นตัวชี้วัดเงินเฟ้อที่ สาธารณชนรับรู้มากที่สุด และใช้ปรับค่าแรง สวัสดิการสังคม และสัญญาต่าง ๆ
🔴ระวัง: CPI > 3% ต่อเนื่อง → ซื้อของแพงขึ้น กำลังซื้อลด กดดัน Fed ขึ้นดอกเบี้ย
🟢ดี: CPI อยู่ที่ 2–2.5% → เงินเฟ้อในระดับเป้าหมาย เศรษฐกิจสมดุล
⚠️จับตา: หมวดที่อยู่อาศัย (Shelter) มีน้ำหนัก ~33% ใน CPI มักเคลื่อนไหวช้ากว่าตลาดจริง
เผยแพร่โดย BLS
เป้าหมาย Fed ~2%
ออกทุก ต้นเดือน
🎯
Core CPI
ดัชนีราคาผู้บริโภคพื้นฐาน — ไม่รวมอาหารและพลังงาน
CPI ที่ตัดหมวดอาหารสดและพลังงาน (น้ำมัน ก๊าซ) ออก เนื่องจากสองหมวดนี้มีความผันผวนสูงจากปัจจัยฤดูกาลและภูมิรัฐศาสตร์ Core CPI จึง สะท้อนแรงกดดันเงินเฟ้อพื้นฐาน ที่ถาวรกว่า นักวิเคราะห์และ Fed ใช้ตัวนี้ประเมินทิศทางนโยบายการเงินระยะกลาง
🔴ระวัง: Core CPI ไม่ยอมลด → เงินเฟ้อฝังรากลึก Fed ต้องคงดอกเบี้ยสูงนาน
🟢ดี: Core CPI ลงสู่ 2–2.5% → ส่งสัญญาณว่า Fed สามารถลดดอกเบี้ยได้
💡เทียบกับ CPI: ถ้า CPI สูงแต่ Core ต่ำ → เป็นเพราะราคาพลังงาน ไม่ใช่เงินเฟ้อโครงสร้าง
เผยแพร่โดย BLS
เป้าหมาย Fed ~2%
ออกพร้อม CPI
💳
PCE Price Index
Personal Consumption Expenditures — YoY %
วัดการเปลี่ยนแปลงราคาสินค้าและบริการที่ผู้บริโภคจ่ายจริง ครอบคลุมทั้งที่จ่ายเอง และที่จ่ายแทน (เช่น ประกันสุขภาพจากนายจ้าง) PCE ต่างจาก CPI ตรงที่ ปรับ basket สินค้าได้ตามพฤติกรรมจริง Fed ใช้ตัวนี้เป็นเกณฑ์หลักกำหนดเป้าเงินเฟ้อ 2%
🔴ระวัง: PCE > 2.5% ต่อเนื่อง → Fed มีเหตุผลคงหรือขึ้นดอกเบี้ย
🟢ดี: PCE ใกล้ 2% → บรรลุเป้า Fed มีพื้นที่ลดดอกเบี้ย
💡vs CPI: PCE มักต่ำกว่า CPI ~0.3–0.5% เพราะน้ำหนักสุขภาพและการศึกษาต่างกัน
เผยแพร่โดย BEA
เป้าหมาย Fed 2.0%
ออกทุก สิ้นเดือน
🎯
Core PCE Price Index
PCE พื้นฐาน — ไม่รวมอาหารและพลังงาน
ตัวชี้วัดที่ Fed ให้ความสำคัญสูงสุด ในการตัดสินใจนโยบายการเงิน เป็น PCE ที่ตัดราคาอาหารและพลังงานออก ทำให้สะท้อนแนวโน้มเงินเฟ้อระยะยาวได้แม่นยำที่สุด ประธาน Fed มักอ้างอิงตัวเลขนี้โดยตรงในแถลงการณ์
🔴ระวัง: Core PCE > 2.5% → Fed ยังไม่มั่นใจ อาจชะลอหรือย้อนกลับการลดดอกเบี้ย
🟢ดี: Core PCE ลงสู่ 2% → Fed มีความมั่นใจสูงว่าเงินเฟ้ออยู่ในเป้า
⚠️จับตา: ดู Super Core PCE (บริการไม่รวมที่อยู่อาศัย) เป็นตัวชี้นำที่ละเอียดกว่า
เผยแพร่โดย BEA
เป้าหมาย Fed 2.0% (ตัวนี้)
ออกทุก สิ้นเดือน
👷
Non-Farm Payrolls (NFP)
การจ้างงานนอกภาคเกษตร — รายเดือน
จำนวนตำแหน่งงานใหม่ที่เพิ่มขึ้นในภาคธุรกิจ รัฐบาล และอุตสาหกรรม ยกเว้นเกษตรกรรม ทหาร และแรงงานอิสระ เป็นรายงานที่ ตลาดจับตามองมากที่สุดในโลก ออกทุกวันศุกร์แรกของเดือน ตัวเลขที่สูงแสดงว่าเศรษฐกิจยังแข็งแกร่ง แต่อาจกดดันเงินเฟ้อผ่านค่าแรง
🔴ระวัง: NFP ติดลบ → ระวังเศรษฐกิจถดถอย; NFP สูงมาก (>300K) → Fed อาจขึ้นดอกเบี้ย
🟢ดี: NFP +150–200K/เดือน → ตลาดแรงงานสมดุล ไม่ร้อนเกินไป
💡ดูประกอบ: Unemployment Rate และ Labor Force Participation Rate
เผยแพร่โดย BLS
ระดับปกติ +150–250K
ออกทุก ศุกร์แรกของเดือน
💰
Average Hourly Earnings (AHE)
ค่าจ้างเฉลี่ยรายชั่วโมง — YoY %
อัตราการเติบโตของค่าแรงเฉลี่ยรายชั่วโมงของแรงงานเอกชน เทียบปีก่อน เป็นตัวชี้วัด แรงกดดันเงินเฟ้อจากต้นทุนแรงงาน ค่าแรงที่สูงขึ้นหมายถึงธุรกิจมีต้นทุนสูงขึ้น มักถูกส่งต่อเป็นราคาสินค้า ขณะเดียวกันก็บ่งบอกกำลังซื้อผู้บริโภค
🔴ระวัง: AHE > 4% ต่อเนื่อง → ค่าแรงเร่งตัวเกินผลิตภาพ เสี่ยงเงินเฟ้อจากต้นทุน (wage-price spiral)
🟢ดี: AHE 3–3.5% → ค่าแรงเพิ่มสอดคล้องกับผลิตภาพ เศรษฐกิจสมดุล
⚠️จับตา: ดูร่วมกับ NFP — ค่าแรงสูง + งานเยอะ = ตลาดแรงงานร้อนแรง
เผยแพร่โดย BLS
ระดับสมดุล ~3–3.5% YoY
ออกพร้อม NFP
🚢
Import Prices
ดัชนีราคานำเข้า — YoY %
วัดการเปลี่ยนแปลงราคาสินค้าที่สหรัฐฯ นำเข้าจากต่างประเทศ เทียบปีก่อน เป็นตัวบ่งชี้ แรงกดดันเงินเฟ้อจากภายนอกประเทศ ได้รับอิทธิพลจากค่าเงินดอลลาร์ ราคาน้ำมันโลก ห่วงโซ่อุปทาน และนโยบายภาษีนำเข้า สะท้อนเงินเฟ้อก่อนที่จะถึงมือผู้บริโภค
🔴ระวัง: Import Prices สูงขึ้นเร็ว → ต้นทุนนำเข้าแพง กดดัน CPI ตามมา 1–3 เดือน
🟢ดี: Import Prices ติดลบหรือทรงตัว → ดอลลาร์แข็ง/สินค้าโลกถูกลง ช่วยลดเงินเฟ้อ
⚠️จับตา: ภาษีนำเข้า (tariffs) ผลักราคาขึ้นโดยตรง ดูนโยบายการค้าประกอบ
เผยแพร่โดย BLS
ชี้นำ CPI ล่วงหน้า 1–3 เดือน
ออกทุก กลางเดือน
🔗 ความสัมพันธ์ระหว่างตัวชี้วัด
ห่วงโซ่เงินเฟ้อ: Import Prices ↑ → ต้นทุนธุรกิจสูงขึ้น → CPI/PCE ↑ → Fed ขึ้นดอกเบี้ย → การบริโภคชะลอ → เงินเฟ้อลด
ห่วงโซ่แรงงาน: NFP แข็งแกร่ง → AHE ↑ → กำลังซื้อสูง → Demand-pull Inflation → Core CPI/PCE ↑
เป้าหมาย Fed: ต้องการ Core PCE ที่ 2% + ตลาดแรงงานสมดุล (full employment) — สองเป้าหมายนี้มักขัดกันในช่วงที่เศรษฐกิจร้อนแรง
